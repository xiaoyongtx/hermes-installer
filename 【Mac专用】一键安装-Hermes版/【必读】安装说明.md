# Hermes + Obsidian + Claudian 一键安装包（Mac版）

> 双击运行 `.command` 文件，5-15 分钟自动完成所有安装和配置。

---

## 📦 安装内容

| 组件 | 说明 |
|------|------|
| Homebrew | macOS 包管理器（已有则跳过） |
| Python 3.11+ | Hermes 运行环境 |
| Hermes Agent | AI agent |
| CC-Switch | 模型切换工具，管理 API Key 和模型配置 |
| Obsidian | 知识库主程序 |
| Claudian 插件 | Obsidian 中的 AI 对话窗口（含 Hermes 集成） |

## 🚀 使用步骤

### 1. 运行安装脚本

双击 `【Mac专用】一键安装-Hermes版.command`

- 首次运行可能提示"无法验证开发者"，右键 → 打开即可
- 安装过程中需要输入电脑密码（输入时不会显示，输完回车）

### 2. 打开 CC-Switch 配置模型

打开 CC-Switch 应用，配置：
- API Key
- API Base URL
- 默认模型

CC-Switch 会自动管理 Hermes 的配置文件。

### 3. 打开 Obsidian

1. 打开 Obsidian
2. 选择知识库路径（安装完成后会显示）
3. 设置 → 第三方插件 → 关闭安全模式 → 启用 Claudian 插件
4. 在 Claudian 插件中切换到 Hermes provider

## ❓ 常见问题

### Q: DeepSeek 模型 401 错误？

如果使用 DeepSeek 模型，需要将配置文件中的 `name` 改为不与内置冲突的名称：

```yaml
# ~/.hermes/config.yaml
custom_providers:
- name: deepseek-custom  # 避免与内置 deepseek 冲突
  base_url: https://api.deepseek.com/
  api_key: your-api-key
  api_mode: anthropic_messages
```
