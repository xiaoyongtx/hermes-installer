# Hermes + Obsidian 一键安装包（Windows版）

面向内容创作者的零门槛安装包，一键搭建「Hermes + Obsidian + Claudian 插件 + CC-Switch」的内容生产系统。

## 📦 安装内容

| 组件 | 说明 |
|------|------|
| Python 3.11 | Hermes 运行环境 |
| Hermes Agent | AI agent |
| CC Switch | 模型切换工具，一键管理 API Key 和模型 |
| Obsidian | 知识库主程序 |
| Claudian 插件 | 在 Obsidian 中与 AI 对话的窗口 |

## 🚀 使用步骤

### 1. 下载缺少的安装包

由于网络原因，以下安装包需要手动下载，放入 `installers/` 目录：

| 文件 | 下载地址 |
|------|---------|
| Obsidian-Setup.exe | https://obsidian.md/download |

### 2. 运行安装脚本

双击 `【Windows双击我】一键安装-Hermes版.bat`

- 可能需要管理员权限
- 安装过程中如有防火墙提示，请允许

### 3. 配置和使用

1. 安装完成后自动打开 CC Switch，配置 API Key 和模型
2. 打开 Obsidian → 选择知识库路径
3. 设置 → 第三方插件 → 关闭安全模式 → 启用 Claudian 插件

## ❓ 常见问题

### Q: DeepSeek 模型 401 错误？

如果使用 DeepSeek 模型，需要将配置文件中的 `name` 改为不与内置冲突的名称：

```yaml
# ~/.hermes/config.yaml
custom_providers:
- name: deepseek-custom  # 避免与内置 deepseek 冲突
  base_url: https://api.deepseek.com/
  api_key: your-api-key
  api_mode: anthropic_messages
```
