这是一个用于创建"Bento Grid等级分层图"的完整提示词模板。
适用于对任何领域的产品、作品、品牌等进行五级分层评级。

---

## 🎯 五级分层定义

### 第1级（最高层）：夯 (Hāng)

**调研填充标准**：
- 该领域内目前公认的"版本之子"
- 具有统治级热度
- 无可争议的顶流产品/作品

**视觉表现**：
- 占据画面最上方或最大的版面模块
- 色调：爆裂红与辉煌金
- 带光晕或能量外溢的视觉特效
- 字体最大、最粗
- 配以极简赞美短语（如"全网吹爆"、"神作"、"版本答案"）

### 第2级：顶级

**调研填充标准**：
- 硬核实力派
- 口碑极佳
- 行家首选的优质项目

**视觉表现**：
- 位于第二层
- 色调：燃烧橙与金属银
- 设计扎实、富有质感
- 展示代表性实力派产品

### 第3级：人上人

**调研填充标准**：
- 优越之选
- 品味在线
- 买了/看了绝对不亏的中坚力量
- 代表了一定的鉴赏力

**视觉表现**：
- 位于中层
- 色调：柠檬黄与冷灰
- 设计风格现代、清爽
- 展示代表性优质中产产品

### 第4级：NPC

**调研填充标准**：
- 毫无记忆点的大众脸产品
- 凑数的工业流水线产物
- 无功无过，容易被遗忘
- **必须写上具体产品/品牌/人名，不要含糊其辞**

**视觉表现**：
- 位于中下层
- 色调：面包色/米色或纸板棕
- 设计普通、重复、缺乏个性
- 展示非常平庸的产品

### 第5级（最底层）：拉完了

**调研填充标准**：
- 公认"避雷针"、"智商税"
- 灾难级失败产品
- 甚至不如没有的存在
- **必须写上具体产品/品牌/人名，不要含糊其辞**

**视觉表现**：
- 挤在画面最底部或角落
- 视觉空间被压缩
- 色调：绝望黑、惨白
- 带明显的数字故障（Glitch）、破碎或腐烂的视觉效果
- 配以警示性短语（如"快逃"、"大冤种"、"别买"）

## ⚠️ 重要提示

1. **必须填写具体名称**：第4级和第5级必须写具体的品牌/产品/人名，不要用"各种"、"某些"等模糊词
2. **调研后再填写**：确保分级准确，基于真实市场情况
3. **视觉落差明显**：第1级最大，第5级最小，中间逐级递减
4. **配色严格执行**：每级的色调和视觉效果必须符合定义
5. **极简短语**：每个等级配上对应的短语，增强表达力

## 🎨 使用方法

### 方法1：使用 CozeImageGenerator 类

```python
from examples.quick_start import CozeImageGenerator

gen = CozeImageGenerator("YOUR_TOKEN", "YOUR_WORKFLOW_ID")

# 方式A：简单模式
result = gen.generate_bento_tier_chart("2024年智能手机")

    "tier_1": ["VS Code"],
    "tier_2": ["JetBrains", "Neovim"],
    "tier_3": ["Sublime Text", "Vim"],
    "tier_4": ["Atom", "Brackets"],
    "tier_5": ["记事本写代码"]
}
result = gen.generate_bento_tier_chart("代码编辑器", tiers)
```

### 方法2：直接调用工作流

```python
import subprocess
import json

params = {
    "input": "创建一张关于XXX的Bento Grid等级分层图。第1级（夯）：...。第2级：...。"
}

with open('params.json', 'w', encoding='utf-8') as f:
    json.dump(params, f, ensure_ascii=False)

with open('params.json', 'r', encoding='utf-8') as f:
    params_str = f.read()

result = subprocess.run([
    'python', 'scripts/coze_workflow.py',
    '--token', 'YOUR_TOKEN',
    '--workflow-id', 'YOUR_WORKFLOW_ID',
    '--parameters', params_str
], capture_output=True, text=True, encoding='utf-8')

print(result.stdout)
```
