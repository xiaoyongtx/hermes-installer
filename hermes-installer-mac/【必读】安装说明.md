# Hermes + Obsidian + Claudian 一键安装包（Mac版）

> 双击运行 `.command` 文件，5-15 分钟自动完成所有安装和配置。

---

## 📦 安装内容

| 组件 | 说明 |
|------|------|
| Homebrew | macOS 包管理器（已有则跳过） |
| Python 3.11+ | Hermes 运行环境 |
| Hermes Agent | NousResearch 的 AI 编码代理 |
| CC-Switch | 模型切换工具，管理 API Key 和模型配置 |
| Obsidian | 知识库主程序 |
| Claudian 插件 | Obsidian 中的 AI 对话窗口（含 Hermes 集成） |

## 🚀 使用步骤

### 1. 运行安装脚本

双击 `【Mac专用】一键安装-Hermes版.command`

- 首次运行可能提示"无法验证开发者"，右键 → 打开即可
- 安装过程中需要输入电脑密码（输入时不会显示，输完回车）

### 2. 打开 CC-Switch 配置模型

打开 CC-Switch 应用，配置：
- API Key
- API Base URL
- 默认模型

CC-Switch 会自动管理 Hermes 的配置文件。

### 3. 打开 Obsidian

1. 打开 Obsidian
2. 选择知识库路径（安装完成后会显示）
3. 设置 → 第三方插件 → 关闭安全模式 → 启用 Claudian 插件
4. 在 Claudian 插件中切换到 Hermes provider

## 📁 安装包结构

```
hermes-installer-mac/
├── 【Mac专用】一键安装-Hermes版.command   ← 双击运行
├── 【必读】安装说明.md                     ← 本文件
├── installers/
│   ├── Obsidian-mac.dmg                  ← Obsidian 离线安装包
│   ├── hermes-agent.tar.gz              ← Hermes Agent 离线源码包
│   └── CC-Switch.dmg                    ← CC-Switch 模型切换工具
├── plugins/
│   └── realclaudian/                     ← Claudian 插件
└── vault/                                ← 知识库模板
```

所有依赖均已离线打包，无需联网下载（仅 Python 依赖需要 pip install）。

## ❓ 常见问题

### Q: 提示"无法验证开发者"怎么办？

右键 `.command` 文件 → 打开 → 打开

### Q: 安装过程中下载失败？

确保已开启 VPN/代理工具，或手动下载 `installers/Obsidian-mac.dmg` 放入 `installers/` 目录。

### Q: 如何修改 Hermes 模型？

打开 CC-Switch 应用，在界面中切换模型和 Provider。

### Q: 如何更换 API Key？

打开 CC-Switch 应用，在设置中修改 API Key。

### Q: run-hermes 报 EACCES 错误？

运行：`chmod +x ~/.obsidian/plugins/realclaudian/run-hermes`
